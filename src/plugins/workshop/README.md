# Плагин `workshop` — 3rd-theme workshop

Страница расширения, где студенты делятся оформлением LMS: палитрой и своим
CSS, логотипом и фонами, обложками и названиями курсов. Открывается вкладкой:
кнопкой с логотипом 3rd party в левом верхнем углу оверлея меню на LMS (вне
самого меню, `_shared/plugin_page_loader.js`) или в попапе — «Тема» →
«3rd-theme workshop» → «Открыть 3rd-theme workshop».

Сервер — отдельный репозиторий
[lms-workshop](https://github.com/cu-3rd-party/lms-workshop):
FastAPI, Postgres и админка модерации. Адрес зашит в трёх местах:
`workshop_api.js`, `src/workshop-background.ts` и `host_permissions` в
`manifest.config.js`.

## Комнаты

Темы публикуют в комнаты. Общая (`PUBLIC`) есть у всех без вступления, и
каждая новая тема и каждая её версия там сначала проходит модерацию: пока
админ не одобрил, версию видит только автор, а остальные видят и ставят
прежнюю.

Приватную комнату создаёт кто угодно: у неё своё название и случайный код из
шести символов, войти можно только по коду. Модерации там нет — тема видна
сразу. Владелец переименовывает комнату, меняет код (старый перестаёт
пускать, участники остаются), удаляет чужие темы и выгоняет участников.
Выгнанный не войдёт по коду, пока владелец не снимет запрет.

## Тема

Тема — это профиль настроек вида `workshop` (см.
[`PROFILE-FORMAT.md`](../../../PROFILE-FORMAT.md)) плюс название, описание,
картинка главного экрана и до шести скриншотов. У темы есть версии; при
установке можно выбрать любую опубликованную.

Состоит из слоёв — их видно галочками и при публикации, и при установке:

| Слой            | Ключи                                                  |
| --------------- | ------------------------------------------------------ |
| Палитра и CSS   | `customTheme*`                                         |
| Переключатели   | остальное из `appearance`: тёмная тема, OLED, снег…    |
| Логотип и фоны  | `customLogo`, `customBackground`, `customBackground.*` |
| Обложки курсов  | `courseIcons`                                          |
| Названия курсов | `courseNames`, `customCourseNamesToggle`               |

Какой ключ к какому слою относится, решает `layerOf` в
`_shared/settings_registry.js`. Тот же список есть на сервере, но там он
только для показа.

## Установка и примерка

Тема **заменяет** оформление целиком. Перед записью снимается всё, что
стоит сейчас во всех слоях (`storedKeys('workshop')` и `reset` реестра):
прежняя тема, своя палитра, логотип, фоны, обложки и названия курсов — даже
если в новой теме этих слоёв нет. Иначе от старой темы оставались бы фоны и
переименования, и выглядело бы это как смесь двух тем. Галочки слоёв решают
только, что взять из новой темы; неотмеченное остаётся по умолчанию.
Названия и обложки применятся только к тем курсам, что есть у поставившего, —
ключи в них по id курса.

**Примерка** — та же установка, но с запасным выходом. Перед записью темы
реестр снимает текущие значения всех затронутых ключей (`snapshot`) — и тех,
что тема запишет, и тех, что снимутся перед ней, снимок
вместе с темой ложится в `workshopTryOn`, и вкладка LMS выходит вперёд. Пока
снимок лежит, внизу страниц LMS висит плашка (`_shared/workshop_tryon.js`) с
кнопками «Оставить» и «Вернуть как было»; то же самое — полосой в самой
мастерской. Обе шлют `WORKSHOP_TRYON_END` в background, и возврат снимка
написан один раз — в `src/workshop-background.ts`. Примерка поверх примерки
сначала откатывает первую: иначе снимок второй темы запомнил бы первую вместо
своих настроек.

Что установлено, лежит в `workshopInstalled` (`themeId → версия`): по нему в
витрине видно «стоит сейчас» и «есть обновление». Раз новая тема снимает
прежнюю, запись там одна.

**Какая тема стоит** — карточка над комнатами. Обычно установленная одна;
несколько остаётся у тех, кто ставил темы, когда они ложились друг на друга, —
тогда «стоит сейчас» последняя по `installedAt`. Пока идёт
примерка, карточка показывает её. Из мастерской ничего не стоит, но включена
своя тема из редактора — показывается её название, иначе «Тема по умолчанию».

## Тема по умолчанию

Кнопка «Поставить тему по умолчанию» в боковой панели возвращает LMS к виду
свежей установки: удаляет из хранилища ключи выбранных слоёв
(`storedKeys` и `reset` реестра), и плагины берут свои значения по умолчанию.
По умолчанию отмечены все слои, кроме названий курсов — их человек обычно
переименовывал сам. Сервер для этого не нужен: кнопка работает, даже если
мастерская не загрузилась.

Сброс тоже можно примерить: в `workshopTryOn` ложится снимок с
`isDefault: true` вместо темы, и плашка на LMS пишет «тема по умолчанию».
Оставили сброс (из мастерской или с плашки) — `workshopInstalled` очищается:
чужих тем больше нет.

## Кто ты

Авторизация — та же, что у биржи обмена парами: случайный ключ устройства
(`workshopDeviceKey`) плюс `student_id` из LMS. Его достаёт background
(`WORKSHOP_IDENTITY`): у страницы расширения нет кук LMS. Из
`/students/me` дальше background уходит только id. Ник выбирают сами — его
видят под темами и в списке участников комнаты.

Safari к запросам background кук LMS не прикладывает (защита от межсайтового
отслеживания), и LMS отвечает 401 даже вошедшему студенту — мастерская
писала «не открылся, войди в LMS». Поэтому на 401/403 background
переспрашивает `/students/me` из открытой вкладки LMS
(`scripting.executeScript`, активная вкладка первой): там запрос свой, и куки
уходят. Нет вкладки LMS — мастерская просит её открыть; вкладка тоже не
вошла — просит войти. Логика — `src/workshop-identity.ts`, тест —
`tests/source/workshop-identity.test.ts`.

## Файлы

| Файл                             | Что делает                                                                |
| -------------------------------- | ------------------------------------------------------------------------- |
| `workshop.html` / `workshop.css` | Каркас страницы: комнаты слева, витрина справа                            |
| `workshop_api.js`                | Клиент сервера, регистрация устройства, сборка картинок обратно в `data:` |
| `workshop.js`                    | Витрина, тема, публикация, «Мои темы», управление комнатой                |
| `../_shared/workshop_tryon.js`   | Плашка примерки на страницах LMS                                          |
| `../../workshop-background.ts`   | `student_id`, вкладка LMS, конец примерки, отметка об установке           |
| `../../workshop-identity.ts`     | Откуда брать `student_id`: background или вкладка LMS (Safari)            |

Все ключи мастерской — в группе `private` реестра: в профили и в сами темы
они не попадают.

## Разработка

Страница ходит на `https://lms.workshop.cu3rd.ru`. Чтобы направить её на
локальный сервер, положи адрес в `storage.local` (например, из консоли
попапа):

```js
chrome.storage.local.set({ workshopBackendUrl: 'http://127.0.0.1:8765' });
```

Сквозной тест — `tests/workshop.test.ts`, как его запускать, написано в его
шапке.
