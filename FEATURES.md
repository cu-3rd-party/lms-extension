# Полный список функций расширения CU LMS Enhancer

Расширение работает на обоих доменах LMS — `my.centraluniversity.ru` и `my.cu.ru` — и добавляет следующие возможности, сгруппированные по области применения.

---

## Глобальные (все страницы LMS)

| Функция                     | Включение                                                        | Описание                                                                                                                                                                                       |
| --------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Тёмная тема**             | Попап → «Тема» → «Тёмная тема»                                   | Полная тёмная тема для всего LMS, включая Shadow DOM компоненты, новые табы на странице «Мои курсы» и карточки курсов (cu-course-card)                                                         |
| **OLED-тема**               | Попап → «Тема» → «OLED»                                          | Абсолютно чёрный фон для OLED-экранов (расширение тёмной темы)                                                                                                                                 |
| **Кнопка меню расширения**  | Всегда включена                                                  | Добавляет кнопку в шапку сайта для быстрого доступа к настройкам                                                                                                                               |
| **Вкладка «Друзья»**        | Попап → «Друзья» → «Вкладка и виджет «Друзья»»                   | Новая вкладка в навигации — список одногруппников с отметкой общих курсов                                                                                                                      |
| **Снег**                    | Попап → «Оформление» → «Эффект снега»                            | Анимация падающих снежинок поверх страницы (праздничная фишка)                                                                                                                                 |
| **Кастомные иконки курсов** | Попап → «Курсы» → «Открыть редактор курсов»                      | Замена стандартных иконок карточек курсов на любые картинки/стикеры                                                                                                                            |
| **Экспорт оценок в Excel**  | Попап → «Оценки» → «Экспорт в Excel»                             | Скачивает `.xlsx` по текущим курсам, а отдельной кнопкой — по архивным: горизонтальные категории, названия задач, пустые слоты до плана, цвета и формулы прогноза по 10-балльной шкале         |
| **Проверка версии**         | Всегда включена                                                  | Уведомляет в шапке, если установленная версия расширения устарела                                                                                                                              |
| **Сброс данных LMS**        | Кнопка в меню                                                    | Очищает кэш фильтров и список друзей из localStorage                                                                                                                                           |
| **Фикс цвета иконок**       | Всегда включен                                                   | Исправляет отображение SVG-иконок при нестандартных темах                                                                                                                                      |
| **Анонимная статистика**    | Попап → «Настройки» → «Анонимная статистика» (по умолчанию вкл.) | Раз в сутки — версия, сборка и какие функции включены, плюс цели на действия (выгрузка оценок, PDF, обмен пар…) в Яндекс Метрику. Данные из LMS не уходят. Подробно — [METRICS.md](METRICS.md) |

## Страница списка курсов (`/learn/courses/view`)

| Функция                         | Включение                                                                                                                    | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Старый дизайн карточек**      | Попап → «Курсы» → «Старый дизайн карточек»                                                                                   | Возвращает карточки-обложки с подписью снизу. Свои картинки ставятся в режиме редактора («Открыть редактор карточек»); в том же разделе — заполнение и масштаб картинки                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Свои названия курсов**        | Попап → «Курсы» → «Свои названия курсов»                                                                                     | Переименовывает курсы везде: список, задания, ведомости, крошки, заголовок курса. Работает и без обложек; расширение и сайт продолжают работать с настоящими названиями                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Картинка на фоне**            | Попап → «Оформление» → «Своя картинка на фоне»                                                                               | Меняет заливку под островками интерфейса на свою картинку. Кнопка «Редактор фона» открывает панель на странице: свой фон для этой страницы, всего курса, раздела или всех страниц. Режимы вставки и плотность подложки; шапка, меню и карточки остаются непрозрачными                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Своя тема (палитра)**         | Попап → «Тема» → «Своя тема»                                                                                                 | Свои цвета поверх светлой или тёмной темы: подписанные переменные интерфейса плюс произвольный CSS. Редактор открывается отдельной вкладкой; пока он открыт, ПКМ по элементу на странице LMS показывает его цвета и переменные. Ещё колорпикер по месту в CSS, справка по всем переменным плагина с подписями и выгрузка применённых стилей. Готовой темой делятся кнопками «Сохранить тему в файл» и «Загрузить тему из файла» в том же разделе меню                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Меню со вкладками**           | Попап расширения                                                                                                             | Слева список вкладок (Тема, Оформление, Курсы, Сроки, Задания, Оценки, Друзья, Настройки), справа — настройки выбранной; листается только правая часть. Открытая вкладка запоминается, по вкладкам ходят и стрелками. В окне попапа меню 800×600, в панели на странице — шире (до 980 px); в узкой панели вкладки уходят в полосу сверху. Новости из GitHub убраны в кнопку «Что нового» в углу меню                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **3rd-theme workshop**          | Меню плагина на LMS → кнопка «3rd-theme workshop» в левом верхнем углу, вне меню (или «Тема» → «Открыть 3rd-theme workshop») | Готовые темы других студентов: палитра и CSS, логотип, фоны, обложки и названия курсов. Общая комната видна всем, новые темы и версии там проходят модерацию; приватные комнаты создаёт кто угодно, вход по шестизначному коду, без модерации — владелец удаляет темы и выгоняет участников. У темы картинка главного экрана, скриншоты и версии; ставится любая версия и по слоям. «Примерить» применяет тему сразу и вешает на LMS плашку «Оставить / Вернуть как было». В боковой панели видно, какая тема стоит сейчас; кнопка «Поставить тему по умолчанию» снимает палитру, логотип, фоны и обложки (тоже можно сначала примерить). Лайки, счётчик установок, жалобы модератору                                                                                                                                                                          |
| **Настройки файлом**            | Попап → «Настройки» → «Настройки файлом»                                                                                     | Выгружает настройки в .json и загружает обратно: отдельно поведение, отдельно визуальный пак с картинками. Токены и кеши в файл не попадают                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Свой логотип ЦУ**             | Попап → «Оформление» → «Свой логотип ЦУ»                                                                                     | Меняет логотип в левом верхнем углу на свою картинку на всех страницах LMS. Картинка готовится как обложки курсов: гифки остаются анимированными, тяжёлые пережимаются, svg сохраняется как есть. Пока включены свои картинки курсов, названия курсов или фон, вместо логотипа ЦУ принудительно стоит надпись «НЕ ЯВЛЯЕТСЯ ОФИЦИАЛЬНОЙ LMS» — заменить её можно только своей картинкой                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Свой архив курсов**           | Редактор курсов → **⇩** на карточке                                                                                          | Прячет курс из списка актуальных (курс остаётся активным в LMS). Работает и без старого дизайна. Вернуть — на странице архивных курсов: курс стоит строкой в самой таблице архива, с кнопкой «Вернуть»                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Архивация курсов**            | Иконка на карточке                                                                                                           | Скрывает ненужные курсы в архив; заархивированные доступны во вкладке «Archived»                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Перетаскивание курсов**       | Встроено в LMS                                                                                                               | Официальная функция drag-and-drop от LMS (cdkDrag) — работает нативно, расширение не требуется                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Статус задач в обзоре курса** | Попап → «Курсы» → «Статус заданий в обзоре курса»                                                                            | В аккордеоне курса рядом с каждой темой показывает статус задания (сдано / просрочено / скип / доработка)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Автоскролл к текущей неделе** | Попап → «Курсы» → «Автоскролл к текущей неделе»                                                                              | При открытии обзора курса автоматически разворачивает и прокручивает к последней (актуальной) теме                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Виджет «Друзья на курсе»**    | Попап → «Друзья» → «Вкладка и виджет «Друзья»»                                                                               | Плавающий виджет на странице курса — показывает, кто из друзей записан на тот же курс                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Предстоящие контрольные**     | Попап → «Сроки» → «Видеть предстоящие контрольные»                                                                           | Отображает в аккордеоне курса даты будущих контрольных и экзаменов (расписание с сервера lms.exams.cu3rd.ru), а в сводной таблице ведомостей — отдельным столбцом недели; формат — разброс дат или номер недели                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Дэшборд на «Мои курсы»**      | Попап → «Сроки» → галочки «Ближайшие контрольные» и «Дедлайны на две недели»                                                 | Полоска под списком курсов из двух частей, каждая включается своей галочкой (обе по умолчанию выключены; можно оставить любую одну). Контрольные — текущая неделя семестра и две следующие: номер недели, даты и контрольные мероприятия по каждому курсу; недели листаются кнопками ‹ › (◎ — к текущей). Дедлайны — 14 дней с сегодняшнего: у каждого «сдано/всего» (3/4) и цвет по числу дедлайнов (1–2, 3–5, 6–9, 10+), закрытый день приглушён; при наведении — задания этого дня со ссылками на задание и курс, сданные с галочкой. Тесты на паре, перезачёты и дорешивания не считаются. Место одно — под курсами. Включается на лету; курсы из своего архива не показываются, свои названия подставляются. Список курсов появляется вместе с полоской: пока данные не пришли (но не дольше 4 с), он спрятан, а запросы уходят ещё до отрисовки страницы |
| **Экспорт материалов курса**    | Всегда включена                                                                                                              | Добавляет виджет на страницу активного курса (`/actual/`) для скачивания всех материалов и ДЗ в ZIP или PDF                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## Страница задач (`/learn/tasks`)

| Функция                          | Включение                                                                     | Описание                                                                                |
| -------------------------------- | ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **Колонка «Вес задания»**        | Всегда включена                                                               | Добавляет в таблицу задач колонку с весом каждого задания в итоговой оценке             |
| **«Метод скипа»**                | Кнопка в строке задачи                                                        | Помечает задание как намеренно пропущенное; отображается кастомным чипом                |
| **Выделение семинаров**          | Всегда включена                                                               | Строки с семинарными заданиями окрашиваются в отдельный цвет для наглядности            |
| **Пользовательские фильтры**     | Поле поиска в таблице                                                         | Фильтрация задач по имени, курсу, статусу прямо в таблице                               |
| **Сброс стандартных фильтров**   | Автоматически                                                                 | При загрузке страницы сбрасывает стандартные фильтры LMS, чтобы показывались все задачи |
| **Скрытие старых заданий**       | Архив задач → поле «Скрывать с дедлайном раньше»                              | Прячет архивные задания с дедлайном раньше выбранного дня; активные задачи не трогает   |
| **Ручное скрытие в архиве**      | Архив задач → «Выбрать и скрыть»                                              | Отмеченные задания пропадают насовсем; «Открыть список скрытых задач» возвращает их     |
| **Замена эмодзи в задачах**      | Попап → «Оформление» → «Сердечки вместо кружков»                              | Заменяет круглые эмодзи (🔵🔴⚫) на сердца (💙❤️🖤) прямо в именах задач                |
| **Прогресс в Яндекс.Контесте**   | Попап → «Задания» → «Яндекс.Контест»                                          | Для задач со ссылкой на contest.yandex.ru показывает бейдж «КОНТЕСТ: решено/всего»      |
| **Фильтр курсов для интеграций** | Попап → «Задания» → списки «Курсы для AKHCheck» и «Курсы для Яндекс.Контеста» | Обе интеграции сканируют только выбранные курсы; пока ничего не выбрано, запросов нет   |
| **Статус входа в Яндекс**        | Попап → «Задания», при включённой интеграции с Контестом                      | Показывает, авторизованы ли вы на contest.yandex.ru, и ссылку на вход                   |

## Страница задания (`/longreads/...`)

| Функция                                | Включение                                      | Описание                                                                                                                                                           |
| -------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Вес задания**                        | Всегда включена                                | Добавляет в метаинформацию задания его вес в итоговой оценке курса (% от финального балла)                                                                         |
| **Просмотр документа в модалке**       | Кнопка рядом с файлом                          | Открывает вложенный документ/изображение в модальном окне без перехода на отдельную страницу                                                                       |

| **Статус «Метод скипа» / «Доработка»** | Связан с tasks_fix                             | Отображает рядом с заданием его особый статус, если задание помечено как скипнутое или требует доработки                                                           |
| **Тёмная тема для PDF**                | Попап → «Тема» → «Тёмные PDF»                  | Перехватывает клик по PDF-вложению, локально перекрашивает документ в тёмную палитру и открывает результат в новой вкладке                                         |

## Страница успеваемости (`/learn/reports/student-performance`)

| Функция                          | Включение                   | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Иконки статусов, подсветка по оценкам, статусам или весу, выделение по клику на легенду и метрики, метка у экзаменов, зачётов, контрольных, коллоквиумов и контестов, колесо мыши листает недели, скрытие ненужных курсов (вернуть — из строки «Скрытые курсы» под таблицей), место под таблицей, скрываемая сводка, сворачиваемая колонка активностей, переключатель семестров, карточка задания при наведении (вес, статус, ссылка). | **Расширенная ведомость**        | Всегда                      | Добавляет детальную разбивку итоговой оценки по категориям (ДЗ, КР, экзамен) с весами и накопленным баллом                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Прогноз итоговой оценки**      | Часть расширенной ведомости | Рассчитывает, какой балл нужно набрать на оставшихся работах, чтобы получить желаемую оценку                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Архивация курсов в ведомости** | Иконка на строке курса      | Скрывает завершённые курсы из основной ведомости; архивные курсы доступны во вкладке архива                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## Страница записи на пары (`/learn/timetable`)

| Функция                 | Включение       | Описание                                                                                                                                      |
| ----------------------- | --------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **Статусы слотов**      | Всегда включено | Чип рядом с типом занятия: «Есть свободные», «Пересечения», «Нет мест» или «1 вариант» — видно, есть ли смысл открывать выбор времени         |
| **Биржа обмена парами** | Всегда включено | На забитых слотах («Нет мест» без пересечения по времени) появляется кнопка «Сделать заказ»: отдаю свой слот, хочу этот                       |
| **Меню «Мои запросы»**  | Всегда включено | Блок под таблицей: способ связи (студпочта, телеграм из ЛК или своя строка), список заказов и найденные совпадения с контактом второй стороны |

Заказы хранит отдельный сервис [lms-swap-backend](https://github.com/cu-3rd-party/lms-swap-backend).
Он ищет взаимные пары — когда двое хотят ровно то, что отдаёт другой — и
раскрывает им контакты друг друга. Дальше студенты пересаживаются сами, а если
оба слота забиты наглухо — через интерфейс LMS это неисполнимо, и меняет их
куратор вручную. Из личного кабинета на сервер уходит только выбранный студентом контакт.

## Посещаемость (`/learn/attendance/courses`)

| Функция                        | Включение                                | Описание                                                                                                                                                                                     |
| ------------------------------ | ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Посещено из прошедших**      | Всегда включено                          | В колонке «За весь семестр» под числом LMS — строка «был / мог быть / всего» (как K/D/A): посещено, уже прошло, за семестр; «был» красится по норме 75%, расшифровка — подписью под таблицей |
| **Вкладка «Сводная»**          | Всегда включено                          | Все курсы сразу: таблица «курс × неделя» со своими семинарами (был / не был / ждёт отметки / впереди) или одна неделя списком со стрелками; норма в процентах — цветом                       |
| **Контрольные в посещаемости** | Попап → «Видеть предстоящие контрольные» | Недели с контрольной помечены флажком: на этих семинарах лучше быть                                                                                                                          |
| **Свои семинары курса**        | Всегда включено                          | На странице курса — все свои семинары семестра с отметками и галочка «Только мой семинар», которая прячет в таблице дня пары чужих групп                                                     |

Считаются только семинары: лекции LMS в посещаемость не отдаёт.
